## Panduan Instalasi

1. Jika sebelumnya sudah pernah memasang build versi debug/uji coba, **uninstall terlebih dahulu** versi lama dari perangkat Anda sebelum menginstal rilis ini (berbeda signing key).
2. Download **`Seren1ty-v2.0.1-release.apk`** dari tab **[Releases](https://github.com/matphen7/serenity-bypass/releases)**.
3. Izinkan instalasi dari sumber tidak dikenal bila diminta oleh sistem Android, lalu pasang aplikasi.
4. Untuk fitur jaringan / script yang membutuhkan akses administrator, pastikan izin superuser diberikan pada root manager Anda (`ReSukiSU`, `KernelSU`, atau `Magisk`).
